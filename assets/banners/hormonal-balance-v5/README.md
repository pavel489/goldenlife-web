# Hormonal Balance — HTML banner a studie

Zdroje nasazené české verze produktu 635. Nadpis, přínosy, počet sáčků a CTA jsou skutečné HTML texty; obrázky jsou pouze autentické logo, produkt a fotografický výřez nápoje. Patička a závěrečná poznámka odstraněné v předchozích revizích se nevracejí. Čtyři odkazy na studie jsou v HTML zachovány.

Aktuální repo používá sdílené produktové CSS a novější produktové skripty. Tato změna vyměňuje výhradně starý Nextida banner a jeho související rozbalovací blok; nepřepisuje celý soubor starší CMS kopií. Ostatní texty, obrázky, tabulky, skripty, jazykové verze a krátký popis zůstávají beze změny.

Živé HTML nadále odkazuje na ověřené existující Shoptet URL. V této složce jsou byte-identické zdrojové soubory pro verzování:

- hb-html-produkt-v5.png — autentický produkt, bez generativní změny obalu.
- hb-html-napoj-v5.jpg — skutečný výřez fotografie nápoje z produktové galerie.

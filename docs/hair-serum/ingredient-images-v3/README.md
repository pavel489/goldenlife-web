## Původ a omezení
Podklady: aktuální produktové HTML v tomto repozitáři, Golden Life brand/RULES.md a pracovní visual-identity.md, obrazová reference zavedené mramorové ingredienční série. Nové snímky požadovaly GPT Image 2 medium přes fal. Capixyl využívá dřívější obecnou laboratorní ilustraci z ingredienční knihovny. Jde o AI ilustrační fotografie, nikoli fotografie dodavatelských vzorků.

Potraviny symbolizují přirozený výskyt vitaminů, ne ověřený výrobní původ konkrétních látek v tomto séru ani přidané INCI ingredience. Výskyt vitaminů: NIH ODS PantothenicAcid-Consumer / Biotin-Consumer, Cleveland Clinic biotin-rich-foods a přehled Peanuts as functional food (PMC4711439). Převzatá účinková tvrzení nejsou touto obrazovou změnou schválena.

Git publikace neznamená vložení do živého Shoptetu.

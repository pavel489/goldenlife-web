# SOS — sjednocení tří ikon do tenké linky
Produkt 473, český krátký i dlouhý popis. Plamen a blesk jsou nově obrysové, vlajka CZ má zeslabenou linku. Všechna tři SVG: fill none, oblé konce/spoje, efektivní stroke 1.32 ve viewBox 64, barva #E40E7E. Tloušťka odvozena od původních ikon trávení a imunity (cca 3 px ze 145 px). Plamen navazuje tvarem na již existující linkový motiv svačinek, v barvě SOS. SVG a skutečné transparentní PNG 256×256 jsou součástí stejné revize. Jde o cílené UI překreslení, ne nový oficiální master značky.
Ostatní čtyři piktogramy, všechny popisky, fotografie, CSS, skripty, tabulky a nákupní logika beze změny. Mění se právě 3 URL v každém poli, celkem 6. Vnější dekorativní kruhové rámečky z předchozí opravy se nevracejí; kruhový obvod českého znaku je jeho vlastní geometrií. Double ani překlady nejsou součástí opravy.
Zdroje: aktuální Git, skutečná SOS stránka, PNG trávení/imunity a předchozí obrysový plamen pro shake, brand/RULES.md a vizuální identita. Model GPT-6.1-sol, SVG/Chromium/Pillow, bez placené obrazové generace; modelový provoz nevyčíslen. Účinkové popisky nejsou změněné ani nově schválené. Živé nasazení a kontrola jsou doložené samostatně v úkolu.

# Woman Balance — nové fotografie aktivních látek

Nahrazeno devět fotografií v devíti kartách a devíti rozkliknutých detailech českého produktu ID 635. Skutečné nahrané JPG byly před zapojením ověřeny načtením z veřejných URL a porovnáním SHA-256 s dodanými obrázky. Zachována přesná složka zadaná zadavatelem: `user/documents/upload/SLIM EXTREME COLLAGEN/`.

V Gitu i v živém Shoptetu se mění pouze odpovídající IMG URL. Každé prostředí vychází z vlastní aktuální zálohy, nikoli přepsání novějším nebo starším layoutem z druhého prostředí. Texty, CSS, skripty, krátký popis a meta popis zůstávají beze změny. Sousední sáčková verze, překlady, ceny ani nastavení nejsou součástí změny.

QA: skutečný živý produkt a samostatný aktuální Git popis v Chromium při šířkách 390, 820 a 1440 px. Každý z devíti dialogů otevřen a zavřen. Anonymní veřejné snímky vedle tohoto souboru. Technické překryvy cookie/newsletter/chat a plovoucí nákupní lišta byly skryty jen v QA prohlížeči, nikoli na produkci. Nejde o test fyzického telefonu či Safari.

Fotografie pocházejí z dodané sady Woman Balance v1: GPT Image 2 medium, fal přes Composio. Toto zapojení nepoužívá žádnou novou placenou generaci. Obrázky jsou AI ilustrace, ne autentické vzorky dodavatele. Potravinové motivy symbolizují přirozený výskyt, nikoli výrobní původ složek; u směsi se ženským ženšenem je vyobrazena schizandra bez tvrzení o neověřeném druhu ženšenu. Převzatá produktová účinková tvrzení nebyla touto URL-only úpravou právně schválena.

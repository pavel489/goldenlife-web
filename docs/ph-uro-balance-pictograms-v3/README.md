# pH+ Uro Balance — piktogramy V3
Šest piktogramů bez vnějších kruhových rámečků; první lístek obrysový. Šestý: „Vylučování přebytečné vody“, nikoli údaj o balení. PNG v této složce s přehledem a zdrojové SVG pro nově kreslený první a šestý symbol v assets/ph-uro-balance/icons-v3/.
Dlouhý a krátký český popis: aktualizován pouze piktogramový pás. Ostatní obsah zachován. Obrázky odkazují na přesný immutable asset commit; Git publikace není uložení do Shoptetu.
Účinkové popisky jsou interní návrh, nikoli právně schválená komunikace. Šestý vychází z původního produktového textu o vylučování tekutin; jeho schválené zdravotní znění není ověřeno. Neúčinková alternativa při zamítnutí tvrzení: „Bylinná čajová směs“. Také původní účinková tvrzení vyžadují posouzení před zveřejněním v e-shopu.

## Co je sjednocené
- Úvodní banner a jeho plný informační panel, vlastní produktové fotografie, původní benefitové ikony, úplné ingredienční dialogy, použití a bezpečnost, tabulky a nákupní CTA.
- Karty po třech na desktopu. Pokud původní produkt nemá potřebný počet ingrediencí, prázdné místo doplňuje výslovně označená informační/CTA karta, nikoli vymyšlená látka. Vitamín C má jednu skutečnou složku a dvě informační karty; Miracle je kosmetické sérum.
- Krátký i dlouhý fragment obsahuje jeden malý STYLE se dvěma importy: společný framework, potom vlastní barevné téma. Původní globální/inline styly a staré nákupní synchronizátory byly nahrazené scoped komponentami.
- **Společný `golden-life-produkt.css` zůstává byte-identický.**
- Jediná nutná změna společného JS: do explicitního allowlistu `golden-life-product-scheme.js` přidáno 13 nových témat, rozhodovací algoritmus nezměněný. Dočasné lokální tea/other-singles detektory byly při rodičovské integraci odstraněny. Všech 26 polí má stejný idempotentní loader s `?v=singles-13-1`; není to 26 samostatných detektorů.
- Při závěrečném 320px short-host testu opravena pouze Bikini Body lokální container-query: dva sloupce benefitů v opravdu úzkém sloupci místo přetékajícího slova. Širší host zůstává ve třech, dlouhé ingredienční řady beze změny.

## Nasazení – samostatný krok, zde neprovedený
1. Zálohovat skutečná editační pole v Shoptetu a vyřešit záznamy v obsahových výhradách. Veřejný snapshot není raw CMS backup.
2. Nahrát 13 vlastních barevných CSS na přesné cesty z manifestu. Společný framework obsahově nevyměňovat, ale musí být dostupný na kanonické URL.
3. Nahrát aktualizovaný **společný JS** a ověřit jeho nové bytes přes `?v=singles-13-1`; nestačí samotné CSS. V nových HTML je loader již připravený. Při dříve nahraném starém globálním inicializátoru je nutné také obnovit jeho include/cache, protože starý allowlist nové produkty nezná.
4. Převzít odpovídající český dlouhý/krátký popis, nikdy jinou variantu balení/příchuti. Poté samostatně readback a plná živá kontrola galerie, tabulek a ovladačů.

8 produktových variant × 3 jazyky × 2 popisy = 48 HTML souborů.

## Rozsah

Slovenština, angličtina a němčina; krátké i dlouhé popisy. Výchozí grafika je český pár z commitu `a5bb8abb7cc36fe702c3a1441e456417b15d0f4e`. České originály, sdílené CSS, produktové fotografie a číselné údaje v tabulkách se nemění. Balíčky a nedokončené české převody nejsou součástí této dávky.

Jde o podklady pro Git a následné vložení. Do živého Shoptetu se tato dávka automaticky neukládá. Překlad původních produktových tvrzení není jejich právní schválení. Specifické obsahové a formulační výhrady jsou v samostatných QA podkladech, nikoli v zákaznickém HTML.
